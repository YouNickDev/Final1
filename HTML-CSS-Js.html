HTML, CSS e JavaScript

Entendendo o HTML: o básico para quem está começando

HTML (HyperText Markup Language) é a linguagem usada para criar páginas na internet. Ele funciona como a estrutura de uma casa: define onde ficam as paredes, portas e janelas — ou, no caso dos sites, os textos, imagens, botões e tudo mais.

Como o HTML funciona?

O HTML organiza o conteúdo usando elementos. Cada elemento é representado por tags. As tags dizem ao navegador (como o Chrome ou o Firefox) como mostrar cada parte da página.

Exemplo de uma tag:

                
                    <!DOCTYPE html>
                        <html>
                        <head>
                            <title>Minha primeira página</title>
                        </head>
                        <body>
                            <h1>Bem-vindo ao meu site!</h1>
                            <p>Este é um parágrafo de exemplo.</p>
                        </body>
                        </html>
    Explicando:
  • <!DOCTYPE html>: Diz que estamos usando a versão moderna do HTML.
  • <html>: Indica o começo da página HTML.
  • <head>: Contém informações sobre a página (título, configurações, links para estilos, etc.).
  • <title>: Define o nome que aparece na aba do navegador.
  • <body>: Contém tudo que será mostrado na página.
  • <p>: é a tag de abertura.
  • </p>: é a tag de fechamento.

Algumas tags importantes para começar

Tag Função Exemplo
<h1> a <h6> Define títulos e subtítulos (h1 é o mais importante, h6 o menos). <h1>Título principal</h1>
<p> Cria parágrafos de texto. <p>Texto do parágrafo.</p>
<a href="URL"> Cria links para outras páginas ou sites. <a href="https://www.exemplo.com">Clique aqui</a>
<img src="URL" alt="Descrição"> Insere imagens na página. <img src="imagem.jpg" alt="Descrição da imagem">
<ul> e <li> Cria listas não ordenadas. <ul><li>Item 1</li></ul>

Dicas de Ouro:

  • Sempre abra e feche as tags corretamente.
  • Use indentação (espaços ou tabulação) para deixar o código mais organizado.
  • Teste criando pequenos projetos, como uma página de apresentação sobre você.


CSS: Estilizando suas páginas HTML

CSS (Cascading Style Sheets) é a linguagem usada para estilizar páginas HTML. Enquanto o HTML define a estrutura, o CSS cuida da aparência: cores, fontes, tamanhos e layout.

Como o CSS funciona?

O CSS aplica estilos a elementos HTML usando seletores. Um seletor pode ser uma tag, uma classe ou um ID. Depois, você define as propriedades que deseja alterar.

Exemplo de um seletor:

                
                    body {
                        background-color: lightblue;
                        font-family: Arial, sans-serif;
                    }
    Explicando:
  • body: é o seletor que indica que estamos estilizando o elemento <body> do HTML.
  • background-color: define a cor de fundo da página.
  • font-family: define a fonte do texto.

Algumas propriedades CSS importantes

Propriedade Função Exemplo
color Define a cor do texto. color: red;
font-size Define o tamanho da fonte. font-size: 16px;
margin Define a margem (espaço) ao redor de um elemento. margin: 10px;
padding Define o preenchimento (espaço interno) de um elemento. padding: 5px;

Dicas de Ouro:

  • Use classes e IDs para aplicar estilos específicos a elementos.
  • Teste diferentes combinações de cores e fontes para encontrar o que mais gosta.
  • Use ferramentas como o DevTools do navegador para ver como as alterações afetam sua página em tempo real.


O que é JavaScript? Explicação simples para iniciantes:

JavaScript é uma linguagem de programação usada para deixar os sites vivos e interativos.

Sabe quando você clica em um botão e uma janela aparece? Ou quando uma imagem muda de tamanho?

Ou ainda quando uma mensagem surge na tela sem precisar recarregar a página?

Tudo isso é possível graças ao JavaScript!

Como o JavaScript funciona?

Quando um site é carregado, o navegador (como Chrome, Firefox ou Safari) lê três tipos de arquivos:

  • HTML: Estrutura do site.
  • CSS: Estilo e aparência.
  • JavaScript: Funcionalidade e interatividade.

O JavaScript é executado direto no navegador, sem precisar instalar nada extra. Ele lê o código e realiza as ações que foram programadas.

O que o JavaScript pode fazer?:

  • Mostrar ou esconder coisas na página.
  • Atualizar partes da página sem recarregar tudo.
  • Fazer animações e efeitos especiais.
  • Validar formulários (por exemplo, conferir se o e-mail foi preenchido corretamente).
  • Criar jogos simples ou até sistemas mais complexos.

Primeiro exemplo de código JavaScript

                
                    <!DOCTYPE html>
                        <html>
                        <head>
                          <title>Teste de JavaScript</title>
                        </head>
                        <body>
                        
                        <h1>Bem-vindo!</h1>
                        
                        <button onclick="mudarTexto()">Clique para mudar o título</button>
                        
                        <script>
                          function mudarTexto() {
                            document.querySelector('h1').innerText = 'Título alterado com JavaScript!';
                          }
                        </script>

                        </body>
                        </html>

  • Criamos uma página HTML normal.
  • Colocamos um botão que chama a função mudarTexto() quando clicado.
  • Dentro da tag <script>, escrevemos o código JavaScript que troca o texto do título (<h1>).</p></ul>
